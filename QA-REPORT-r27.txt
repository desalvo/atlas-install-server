Runtime notes
-------------
PHP/application errors are written to /var/lib/atlas-install/log/php-application.log.
The container entrypoint follows that file and mirrors it to stderr, therefore the
same events are visible with kubectl logs. The file remains available on the
application volume for diagnostics if container log collection is interrupted.

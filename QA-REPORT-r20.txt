Operational note
----------------
When application/auth schema creation needs privileges not granted to dbwriter, the r20 Kubernetes wizard can accept a one-time database bootstrap/admin user and password. The password is placed in the bootstrap Secret only for rollout/bootstrap, then removed automatically after the Deployment becomes Ready. It is not stored in the wizard state file.
